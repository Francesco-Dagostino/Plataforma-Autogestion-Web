# 🧑‍💼 Plataforma de Autogestión

> Portal web de autogestión para empleados, desarrollado como Trabajo Práctico Integrador de Programación IV.

<br />

## ✨ Características

- 🏠 Panel principal con resumen de jornada.
- ⏱️ Visualización de horas trabajadas por día y semana.
- 📊 Gráfico de actividad semanal.
- 🔔 Recordatorios de carga de horas y liquidaciones.
- 📄 Historial de últimas horas registradas.
- 💰 Información sobre próximas liquidaciones.
- 📱 Diseño adaptable a dispositivos móviles y escritorio.
- 🧩 Componentes reutilizables para una interfaz ordenada y escalable.

<br />

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
| :--- | :--- |
| ⚛️ React | Construcción de la interfaz |
| ⚡ Vite | Entorno de desarrollo y compilación |
| 🎨 Tailwind CSS | Estilos y diseño responsive |
| 🟨 JavaScript | Lógica de la aplicación |
| 🔎 ESLint | Análisis y calidad del código |

<br />

## 🖥️ Vista principal

La aplicación cuenta con un panel de empleado donde se puede visualizar información relevante de la jornada laboral:

- Horas registradas durante el día.
- Total de horas acumuladas en la semana.
- Estado de la liquidación actual.
- Actividad semanal representada mediante un gráfico.
- Últimos registros de horas.
- Recordatorios importantes.

## 🚀 Funcionalidades proyectadas

- 🔐 Inicio de sesión y autenticación de usuarios.
- 👤 Gestión de perfiles.
- ⏳ Registro, edición y eliminación de horas trabajadas.
- 📋 Consulta detallada de horas registradas.
- 💵 Gestión de liquidaciones.
- 📈 Generación de reportes.
- 🔔 Sistema de notificaciones.
- 🔄 Integración con la API del backend.
- 🧭 Navegación entre las diferentes secciones de la plataforma.
